Merchant Weight Rounding Metafield Update

Add Weight Rounding Metafield

  • (Go to "Settings" down the bottom left, click on "Metafields and metaobjects" in the lower left)
  • Click on "Products" metafields
  • Click on, select "More actions" and chose "Delete Definition" for the existing "weight rounding value" Product metafield
  • Select "Delete field and its saved values" if prompted
  • Go back to "Products" metafields page if necessary
  • Add the following Product Metafield Definition:
    • Start by clicking "Add definition" if you haven't already.
    • Set the "Name" to "weight rounding"
    • Set the "Type" to "Metaobject"
      • Click the "Metaobject" type and then click "Create new"
      • Set the metaobject "Name" to "weight rounding object"
      • Set the first field label to "weight rounding value"
      • Set the first field type to "Weight"
      • Click "Add field" to add a second field
      • Set the second field label to "weight product variant id"
      • Set the second field type to "Single line text"
      • Click "Save" to save the new Metaobject
    • Once returned to the metafield page, click "Save" again to save the new Metafield.


Update Product Weight Rounding Metafield

  • Go to the "Products" page, search for and select the "aluminium-plate-test" product
  • Scroll down to "Product metafields", click the "weight rounding" field and select "Add new entry"
  • In the first field labeled "weight rounding value", enter 500 (ensure the scale is in grams)
  • In the second field labeled "weight product variant id", enter 49215967265012
  • Click "Save"


  • All done.
